# Playbook roles (generic starter)

Each `<role>/SKILL.md` here is a generic, fill-me-in stub. `init_workspace.py`
wires this folder to `.claude/skills/` (and to Codex via `.agents/skills`) so
Claude Code and Codex CLI discover the roles.

Replace each `SKILL.md` body with your own operating instructions. That content
is *your* playbook: keep it private and out of any public remote. The engine
(templates, harness, MCP source, guardrails) stays generic and shareable; the
tradecraft in these files does not.

See `docs/SKILLS.md` for the role roster and `docs/ENGINE-AND-PLAYBOOK.md` for
the engine/playbook split.
