# Security Hardening Roadmap

StumbleBreach is designed for authorized, human-led security work. The project
is strengthening its native tool layer so technical controls reinforce the
existing scope, review, and evidence process.

Planned work includes constrained scanner options, scope checks for every
network destination, bounded approval records for high-impact operations,
automatic containment of long-running jobs, stronger publication checks, and a
clear untrusted-content boundary for tool output and target material.

These improvements do not expand authorization. Engagement-specific scope,
program rules, and human review remain the authority for every action.
