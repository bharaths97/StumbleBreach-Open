# References

Large methodology, course, and reference repositories are optional local
working aids. Clone or symlink them beneath this directory; `references/`
is ignored and must never be committed as engagement evidence.

For a blockchain engagement, useful local references may be arranged as:

```text
references/
  blockchain/
    Web3-Security-Library -> /path/to/local/Web3-Security-Library
    exercises-part-1 -> /path/to/local/exercises-part-1
    solutions-part-1 -> /path/to/local/solutions-part-1
```

These links are local aids only. Curated notes, commands, traces, or excerpts
needed for a finding must be reviewed and copied into the engagement's normal
tracked evidence paths; do not treat a reference checkout as evidence.
